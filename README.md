# Simple Bank — Beta 0.1.0

A Stardew Valley 1.6 SMAPI mod with an ATM in the Manor House, savings, term deposits, loans, and multiplayer accounts. English and Chinese in-game text are included.

面向《星露谷物语》1.6 的 SMAPI 银行模组，提供村长家 ATM、活期存款、定期存款、贷款和多人账户，支持中英文界面。

当前版本为 `0.1.0-beta`。源码位于 `SimpleBank-0.1.0-beta-source/`，公开构建入口为该目录下的 `build/build.ps1`。生成可安装的主发行包需要真实 Stardew Valley 与 SMAPI 引用；源码 ZIP 不能直接作为模组安装。

This is a beta release. Offline tests do not establish compatibility with the real game, rendering, input, or multiplayer networking. See the verification record for the tested scope.
