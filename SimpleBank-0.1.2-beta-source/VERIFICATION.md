# Simple Bank 验证记录

本文记录 Beta 0.1.2 的当前验证范围，并保留 Beta 0.1.1 和 Beta 0.1.0 的历史记录。离线测试使用游戏接口替身，不能代替真实 Stardew Valley/SMAPI 环境中的构建和实机验收。

## Beta 0.1.2（2026-11-03，尚未发布）

- 主项目、主模组、CP 地图包和可选 MFM 包统一为 `0.1.2-beta`，有效源码目录为 `SimpleBank-0.1.2-beta-source`。
- 同步精简定期和贷款到期当天的中英文提示：定期只显示到期笔数及已转入活期，贷款只显示今日到期与及时还款提醒。移除提示调用中不再使用的金额参数，定期金额汇总仅在调试启用时计算，技术日志保留。通知触发、去重、贷款规则及 schema 3 不变。
- 最终中文句式统一为“X 笔定期存款今日到期，已转入活期。”和“贷款今日到期，请及时还款，避免逾期。”英文同步采用先说明到期状态、再说明处理结果或操作的结构。
- 按最终方案通过 Windows PowerShell 5.1 的统一入口 `build/build.ps1 -GamePath ...`，使用 SDK `10.0.403`、Stardew Valley `1.6.15` 和 SMAPI `4.5.2` 完成静态校验、核心 459 项断言、GameHarness 328 项断言、真实 SMAPI 主 DLL 构建及主包/可选包打包。更新既有中英文通知用例，验证定期笔数与贷款提醒、共享/独立账户、同日重连和去重；断言总数未增加。
- 最终主项目 0 警告、0 错误；两个测试项目各保留 3 条 `NETSDK1138` 生命周期提示，无 `CS9057`。首次构建的 NuGet 在线检查因受限网络产生 `NU1900`；确认网络可达后移走缓存的失败记录，再通过同一入口完整构建，最终不再出现该警告。
- 已核对三个包的 manifest 版本与更新键、主 DLL 版本和哈希，以及打包后的中英文提示。主安装包不携带 `config.json`，源码包保留默认样本并排除本地指令、历史归档和构建缓存。
- 本版已完成本地构建与归档，尚未创建发行标签或发布安装包；旧版本附件未替换。尚未启动实机验收。

## 自动测试覆盖范围

核心测试覆盖：

- 活期交易、逐日结息、小数利息累积、定期到期与提前支取、贷款和逾期利息上限。
- 从钱包或活期开立定期，包含部分、全额、1g 和大额转入，余额不足、产品禁用和数量上限。

GameHarness 覆盖：

- 游戏层源码编译、每屏状态隔离、ATM 会话和多人协调器绑定。
- 中英文菜单输入、定期资金来源选择、确认取消、等待响应时锁定编辑，以及视口变化后的控件边界。

- 定期和贷款到期当天的中英文 HUD、会话去重、定期结算结果过滤、同日重连及每屏隔离。
- 共享与个人主机交易、消息序列化、主机日期、定向快照与账户过滤、重复与陈旧请求、伪造身份拒绝。
