# Simple Bank — Beta 0.1.0

Simple Bank 是一个面向《星露谷物语》1.6 的 SMAPI 模组。它在村长家加入 ATM，并提供活期存款、定期存款、贷款、多人账户和可配置的银行参数。

当前机器版本号为 `0.1.0-beta`；“Beta 0.1.0”是面向玩家的显示名称。

## 运行要求

- Stardew Valley 1.6。
- SMAPI 4.1.0 或更高版本。
- Content Patcher 2.9.0 或更高版本。
- Generic Mod Config Menu 可选；安装后可在游戏内修改银行参数与按键。
- Mail Framework Mod 可选；只用于额外的一次性欢迎信，不影响银行功能。

## 安装

1. 解压主发行包到游戏的 `Mods` 目录。
2. 确认最终目录中同时存在：
   - `Mods/SimpleBank/SimpleBank`
   - `Mods/SimpleBank/[CP] Simple Bank Map`
3. 如需欢迎信，再解压可选 Mail Framework 包；它会加入 `Mods/SimpleBank/[MFM] Simple Bank Notice`。
4. 通过 SMAPI 启动游戏。

所有联机玩家都应安装相同版本的主模组和 Content Patcher 内容包。

## 使用方法

ATM 位于村长家的墙面区域 `(14,8)`–`(15,9)`。站在相邻格并面向 ATM，按游戏的交互键打开菜单。

ATM 有四个页面：

- 概览：账户状态、活期余额、定期汇总和贷款汇总。
- 活期：存入、取出，以及全部、二分之一、四分之一快捷金额。
- 定期：选择“从钱包转入”或“从活期转入”，按启用的期限创建定期存款，或提前终止已有定期。
- 贷款：申请贷款、查看本金和利息，并在二次确认后还款。

键盘默认使用 `Tab` 切换页面，`Esc` 或 `E` 关闭。手柄默认使用左右肩键切换页面、`A` 确认、`B` 返回；方向键和左摇杆均可导航。所有按键可通过 GMCM 调整。

定期页每次打开 ATM 默认选择“从钱包转入”；本次打开期间会记住选择，切换页面后返回也保留。切换来源保留已输入金额，“最大”按所选来源的可用余额填写。每笔定期只使用一种来源，余额不足时提示修改，不自动从另一来源补足。确认页会显示来源、金额、期限和日利率；修改来源、金额或产品后需要重新确认，等待主机响应期间暂时锁定编辑。

## 银行规则

- 活期与定期交易接受任意正整数金币；贷款金额必须是 `1,000g` 的整数倍。
- 活期、定期和贷款利息每日精确计算；不足 `1g` 的部分保存在各自的余数桶中，累积到整金币后再入账，不会因每日取整而丢失或被重复放大。
- 定期到期和贷款最终结清时，剩余的小数利息按远离零方向四舍五入一次；ATM 显示的贷款利息已经包含这笔最终取整金额。
- 定期提前终止会返还本金和已完成天数的活期利息，不支付锁定的定期利息。
- 从活期转入定期只转移整数金币；不足 `1g` 的活期利息余数仍留在原账户，即使转走全部整数余额也会保留。新存单按现有日结规则从次日开始计息。无论开立时使用哪种来源，到期或提前支取所得都进入活期；强制托收期间仍优先用于还债。
- 贷款额度由基础额度、历史总收益比例和绝对上限共同决定，并向下取整到 `1,000g`。
- 贷款到期次日进入逾期宽限；宽限期结束后，主机按合同条款依次抵销活期余额、扫取钱包保留额以上余额，并按比例代扣后续正向收入。
- 未还本金继续按锁定利率乘逾期倍数逐日计算单利；累计逾期利息达到合同上限后才停止新增，不会在无收入时直接跳到上限。
- 托收不会让钱包变为负数，也不没收物品、建筑或未到期定存。定存自然到期或主动提前支取的可用款项会先用于还款。
- 银行交易不会增加游戏的历史总收益，也不会伪造收入成就进度。

默认配置提供 5 个定期产品、3 个贷款产品和额外的禁用槽位。所有利率、期限、额度与产品开关都可在配置中调整，并在载入时进行范围校验。贷款的托收参数会在放款时锁入合同，之后修改 GMCM 只影响新贷款；ATM 确认页会在借款前展示完整条款。

### 逾期与强制托收

默认宽限期为 7 天，因此到期日为 `D` 的贷款在 `D+1` 进入逾期，在 `D+8` 开始托收。默认托收条款为：启用活期抵销、活期保留额 `0g`、钱包保留额 `1,000g`、后续正向收入代扣 `25%`、累计逾期利息上限为原始本金的 `100%`，托收 28 天仍未结清则标记为 `Defaulted`。

`Defaulted` 只表示长期未清偿，并不取消债务：托收继续，利息继续逐日增加至上限，钱包模式切换仍被阻止。玩家没有余额或收入时不会生成空还款；以后获得资金时自动恢复托收。独立钱包玩家离线期间，主机只处理其银行内的活期和自然到期定存，不触碰其他玩家钱包；该玩家重连时只补做当前游戏日尚未完成的一次钱包扫款，不按离线天数重复扣款。

强制托收期间，ATM 禁止提取活期和新建定期；普通存款改为还款，提前支取所得先还款，手动还款始终保留。现实银行中的“抵销权”是活期抵销的产品类比；钱包扫款和游戏收入代扣则是本模组在放款时明确展示并锁定的游戏合同机制。

主机可在 SMAPI 控制台查询或管理异常债务。所有修改命令都要求末尾再次输入 `confirm`，并记录操作者、目标稳定 ID、日期、原债务和结果：

```text
simplebank_debt [playerId]
simplebank_pay <playerId> <amount> confirm
simplebank_cancel_debt <playerId> confirm
simplebank_credit_ban <playerId> <days|permanent> confirm
simplebank_credit_clear <playerId> confirm
```

取消债务与信用限制是互相独立的操作；取消债务不会自动永久禁贷，清除禁贷也不会恢复已取消债务。

默认日利率如下；游戏一年为 112 天：

| 产品 | 日利率 | 本期限理论收益或成本 |
|---|---:|---:|
| 活期 | 0.005% | 112 天约 0.562% 收益 |
| 7 天定存 | 0.010% | 约 0.070% 收益 |
| 14 天定存 | 0.015% | 约 0.210% 收益 |
| 28 天定存 | 0.020% | 约 0.562% 收益 |
| 56 天定存 | 0.025% | 约 1.410% 收益 |
| 112 天定存 | 0.030% | 约 3.417% 收益 |
| 7 天贷款 | 0.15% | 1.05% 成本 |
| 28 天贷款 | 0.10% | 2.80% 成本 |
| 112 天贷款 | 0.06% | 6.72% 成本 |

存款收益按每日复利估算，贷款成本按未偿本金的每日单利计算；最终整数金币以实际余数结算为准。

## 多人模式与钱包切换

主机是存档、日结和交易的唯一权威。客户端只发送交易请求；主机会重新校验玩家身份、ATM 距离、余额、合同、版本和请求频率，再同步结果。

- 共享钱包使用一个共享银行账户。
- 独立钱包按稳定的多人 ID 保存个人银行账户。
- 从共享切换到独立、或从独立切换到共享时，只迁移活期余额及其尚未入账的利息余数。
- 任意账户仍有未结清定期或贷款时，钱包模式切换会被拒绝并在游戏内说明原因。
- 个人账户快照只发送给所属玩家，不会向其他农场工人公开。

## 兼容性基线

`0.1.0-beta` 是新的开发与数据兼容起点。此前所有 `1.x` 包均视为内部开发版本；本版本不包含旧配置字段迁移或旧存档账户修复逻辑，也不承诺导入这些开发版本的数据。

升级前请备份存档，并为 Beta 0.1.0 使用新的配置进行测试。未知或结构无效的银行存档会被保留且锁定写入，以避免静默覆盖可疑数据。

Content Patcher 内容包只在 `Maps/ManorHouse` 写入 `SimpleBankAtmArea` 地图属性，不覆盖墙面、碰撞层或地图图块。ATM 图像由主模组作为世界精灵绘制，因此可与大多数外观重绘共同使用。

## 当前状态

这是 Beta 版本。自动化测试覆盖核心交易、日结、钱包模式迁移、多人消息与分屏会话，但真实游戏中的地图显示、控制器手感、不同 UI 缩放和长期联机仍需要持续实测。
