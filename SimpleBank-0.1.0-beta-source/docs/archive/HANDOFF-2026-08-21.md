# Simple Bank 项目交接报告

## 1. 项目概览

- 项目：Simple Bank —— 星露谷 1.6 / SMAPI 模组，在村长家加入 ATM 与银行系统。
- UniqueID：`Akiba275.SimpleBank`（源码目录 `SimpleBank-1.7.5-source`）。
- 目标框架：`net6.0`。
- 结构：
  - `src/SimpleBank.Core`：纯业务域（无游戏依赖，可单测）。

  - `content/[CP] Simple Bank Map`：Content Patcher 地图标记。
  - `optional/[MFM] Simple Bank Notice`：可选 Mail Framework Mod 信件。

## 4. 新经济模式切换流程（已批准）

- **阶段一（请求预检拦截）**：
  - 监听 `changeWalletTypeTonight` 的 `false→true`。
  - 用 `CheckWalletModeMigration` 双向检测未结清定期/贷款。
  - 有 → 复位 flag + 弹“由于银行账户存在未结清的定期或贷款，无法办理经济模式切换。”
  - 无 → 放行。
- **阶段二（过夜切换迁移）**：
  - 监听 `useSeparateWallets` 变化 → `EnsureWalletMode` → `MigrateWalletMode`。
  - 只合并活期，不迁移定期/贷款。
- **阶段三（请求→过夜窗口兜底）**：
  - `MigrateWalletMode` 在真正切换前再查一次 `HasUnsettledProducts`，出现新开的定期/贷款则拒绝并回滚。
- **废弃的旧逻辑**：旧三阶段对账、`CancelUnsafePendingWalletModeRequest`、`RestoreGameWalletModeToBankState`（ModEntry 版）、`OnUpdateTicked` 旧对账兜底等已删除。

## 5. 当前状态与已知问题

### 已确认正常（实机）

- 共享→独立经济切换拦截正常。

### 仍未解决（最新实机反馈）

1. **非主机退出后，主机 ATM 打不开**。
   - 日志出现 `atm-open-blocked: reason=bank-null, isMainPlayer=True`。
   - 含义：主机 `ModEntry.bank == null`；只有 `OnReturnedToTitle` 会把 `bank` 置 null。
   - 另有 `atm-open-blocked: reason=not-near-atm`（可能是站位太远，也可能是 CP 地图标记丢失，待区分）。

2. **主机账户被重置复现**：定期/活期消失，贷款“无限刷钱但无记录”。

3. **非主机一直等待主机确认**。

4. 因 2/3，暂时无法测“独立→共享”拦截。

### 当前根因判断

- 核心怀疑：**农场工人退出时，主机侧意外触发了 `ReturnedToTitle`（或主机回到标题后银行未被正确重建）**，导致 `bank=null`，连锁引发账户重置、非主机等待等。
- 已补最小生命周期日志（见第 9 节），等待下一次实机日志确认触发顺序。
