## 自动测试覆盖范围

核心测试覆盖：

- 活期交易、逐日结息、小数利息累积、定期到期与提前支取、贷款和逾期利息上限。
- 从钱包或活期开立定期，包含部分、全额、1g 和大额转入，余额不足、产品禁用和数量上限。
- 原子交易、重复与陈旧请求、溢出后的状态与钱包回滚、账户隔离及钱包模式切换。
- 贷款托收顺序、保留额、合同条款锁定、收入代扣余数、同日去重、离线账户处理与重连补扫。
- 债务取消与信用限制分离、配置热更新、存档结构校验、显式 schema 迁移、诊断开关和数据增长上限。

GameHarness 覆盖：

- 游戏层源码编译、每屏状态隔离、ATM 会话和多人协调器绑定。
- 中英文菜单输入、定期资金来源选择、确认取消、等待响应时锁定编辑，以及视口变化后的控件边界。
- 共享与个人主机交易、消息序列化、主机日期、定向快照与账户过滤、重复与陈旧请求、伪造身份拒绝。
- 载入与日开始的托收时序、离线个人账户、同日重连、玩家对象重绑、共享钱包单次观察，以及交易不改变历史总收益。

## 尚需实机验证

- 主项目针对实际 Stardew Valley 1.6 和 SMAPI 的 Release 构建与分析器检查。
- 村长家 ATM 的显示位置、绘制深度、可交互范围和地图重绘兼容性。
- 中英文 GMCM 与 ATM 页面，鼠标、键盘、手柄、75%–150% UI 缩放、小窗口及大金额文本布局。
- 纯远程联机、本地分屏、分屏与远程混合联机中的共享账户竞争操作、请求等待、断线重连和快照到达顺序。
- 保存重载、跨日计息、长期日结、定期到期与提前支取、钱包模式过夜切换。
- 不同收入来源及其他模组改写钱包时的托收顺序、保留额、通知到达顺序和历史总收益不变。
- 可选 MFM 欢迎信的一次性投递。
