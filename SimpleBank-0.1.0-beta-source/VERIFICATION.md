## 2026-10-23 定期存款支持从活期转入

- 定期页增加“从钱包转入／从活期转入”互斥选项，每次打开默认钱包；同一菜单跨页面保留来源，分屏菜单各自保存。切换来源保留金额，“最大”使用所选来源余额，余额不足不混合扣款；修正金额后清除过时的余额不足提示。
- 确认页显示来源、金额、期限和日利率。修改来源、金额或产品会取消原确认，等待主机响应期间锁定编辑。来源选择放在数字键盘下方，定期确认使用左侧完整区域以容纳换行文本。
- 新增 `CreateTermDepositFromActive` 和远程操作 `term-active`，共用定期产品校验与合同创建逻辑，主机一次性提交活期扣款和存单。失败恢复余额、存单、余数、revision 和交易 ID 历史，不经过游戏钱包，也不影响 `totalMoneyEarned`。
- 全额转入仍保留活期小数利息余数，新存单余数为零，计息起点、自然到期、提前支取与托收规则保持一致。来源不写入存单，存档继续使用 schema 3。

## 2026-09-06 小数利息余数

- `BankState` schema 从 1 升级到 2；活动账户、定期存单和贷款合同分别持久化 `[0, 1)` 的利息余数，schema 1 存档显式升级且不掩盖损坏结构。
- 日结不再把每笔不足 `1g` 的利息逐日四舍五入。精确日息与余数相加后只兑现整金币，余数跨日、克隆、存档和钱包模式迁移继续保留。
