# Simple Bank 验证记录

本文记录 Beta 0.1.1 的当前验证范围，并保留 Beta 0.1.0 的发布记录。离线测试使用游戏接口替身，不能代替真实 Stardew Valley/SMAPI 环境中的构建和实机验收。

## 当前版本验证（2026-11-01，0.1.1-beta，尚未发布）

- 主项目与主模组、CP 地图包、可选 MFM 包的版本均为 `0.1.1-beta`；源码目录更名为 `SimpleBank-0.1.1-beta-source`。数据 schema 仍为 3，支持的数据基线仍为 Beta 0.1.0。
- 使用 .NET 10 LTS SDK `10.0.403`（C# 编译器 `5.9.0.0`）、Stardew Valley `1.6.15` 和 SMAPI `4.5.2`，通过公开入口 `build/build.ps1 -GamePath ...` 完成本机完整构建。Windows PowerShell 5.1 与 PowerShell 7.6.5 均在移走各自上一次的 `bin/obj` 输出后独立重建，脚本退出码均为 0；日志确认实际选择 SDK `10.0.403`，主模组和两个测试项目的目标框架均保持 `net6.0`。
- 两个 PowerShell 版本下均通过核心测试 `PASS: 388 assertions` 和 GameHarness `PASS: 166 game-layer lifecycle assertions; game layer compiled.`。真实主项目 Release 构建均为 0 警告、0 错误，旧 SDK 下的 `CS9057` 已消失；未禁用分析器或屏蔽该警告。
- 两个可执行测试项目各产生 3 条 `NETSDK1138`（同一生命周期提示在还原和构建阶段重复出现），均为 0 错误；提示源于 .NET 6 已结束支持，不是 SMAPI 分析器加载失败。保留提示，未更改目标框架或关闭生命周期检查。
- 新增菜单行为测试覆盖中英文到期前、到期当天、逾期、托收及违约显示；随当前游戏日更新剩余天数，贷款详情不重复显示到期信息。
- 申请确认测试覆盖摘要、完整条款翻页、窗口变化、滚轮、手柄确认/返回、编辑金额取消旧确认、取消申请，以及明确确认后仅发放一笔对应贷款。另验证关闭托收和无逾期利息上限配置的显示。字体测量使用替身，只能验证离线几何逻辑。
- 静态校验通过：13 个源码 JSON、版本与配置默认值、中英文键集合、地图、输入、存档和多人边界。银行业务、多人权威、存档结构及欢迎信正文未改动。
- 生成本版可选 MFM ZIP 和源码 ZIP；源码包包含 48 个公开文件，排除本地指令、历史文档及构建缓存。
- 构建入口新增 `BUILD SDK` 日志，显示实际 SDK 版本、工具路径与 `net6.0` 目标；缺少工具时的安装提示改为 .NET 10 LTS SDK。开发说明同步统一构建入口、SDK 与目标框架的区别以及警告解释，业务代码和项目目标框架未修改。
- SDK 10 首次重建时，受限网络导致 NuGet 漏洞数据检查出现 `NU1900`；允许访问 NuGet 后，通过同一入口重新完整构建，两种 PowerShell 下均不再出现该提示，未关闭 NuGet 漏洞检查。
- 本版未发布到 GitHub 或 Nexus，也未启动游戏进行实机验收。下一步仍需验收到期显示、中英文摘要、条款翻页及输入操作。

### 同日 SDK 升级前的构建记录

- .NET SDK `6.0.428` 下，通过 Windows PowerShell 5.1 的同一构建入口生成过真实主 DLL 和安装包；388 项核心断言和 166 项游戏层断言均通过，两个测试项目为 0 警告、0 错误。
- 当时真实主项目为 0 错误、1 条 `CS9057`：SMAPI 分析器要求编译器 `4.9.0.0`，高于旧 SDK 的 `4.3.0.0`，因此当次不能视为分析器检查通过。此问题已由上述 SDK 10 重建解决。
- 最初因无法访问 NuGet 服务索引而报 `NU1301`；校验并复制已有的 `Pathoschild.Stardew.ModBuildConfig 4.4.0` 本地包到脚本默认缓存后，通过同一入口重试成功。

## 自动测试覆盖范围

核心测试覆盖：

- 活期交易、逐日结息、小数利息累积、定期到期与提前支取、贷款和逾期利息上限。
- 从钱包或活期开立定期，包含部分、全额、1g 和大额转入，余额不足、产品禁用和数量上限。
- 原子交易、重复与陈旧请求、溢出后的状态与钱包回滚、账户隔离及钱包模式切换。
- 贷款托收顺序、保留额、合同条款锁定、收入代扣余数、同日去重、离线账户处理与重连补扫。
- 债务取消与信用限制分离、配置热更新、存档结构校验、显式 schema 迁移、诊断开关和数据增长上限。

GameHarness 覆盖：

- 游戏层源码编译、每屏状态隔离、ATM 会话和多人协调器绑定。
- 中英文菜单输入、定期资金来源选择、确认取消、等待响应时锁定编辑，以及视口变化后的控件边界。
- 定期与贷款的剩余天数和日期边界，贷款申请摘要、条款分页及只读查看行为。
- 共享与个人主机交易、消息序列化、主机日期、定向快照与账户过滤、重复与陈旧请求、伪造身份拒绝。
- 载入与日开始的托收时序、离线个人账户、同日重连、玩家对象重绑、共享钱包单次观察，以及交易不改变历史总收益。

## 尚需实机验证

- 村长家 ATM 的显示位置、绘制深度、可交互范围和地图重绘兼容性。
- 中英文 GMCM 与 ATM 页面，鼠标、键盘、手柄、75%–150% UI 缩放、小窗口及大金额文本布局。
- 纯远程联机、本地分屏、分屏与远程混合联机中的共享账户竞争操作、请求等待、断线重连和快照到达顺序。
- 保存重载、跨日计息、长期日结、定期到期与提前支取、钱包模式过夜切换。
- 不同收入来源及其他模组改写钱包时的托收顺序、保留额、通知到达顺序和历史总收益不变。
- 可选 MFM 欢迎信的一次性投递。
